# 窗口插帧助手 · 成品下载

给 macOS 窗口做插帧：抓取任意窗口，在覆盖层里插帧显示，鼠标键盘照常穿透到原应用。

**本仓库只放打包好的成品，不提供源码。**

## 下载

最新版本见 → [Releases](https://github.com/lrylnx/WindowInterp-Releases/releases/latest)

| 包 | 默认内核 | 系统要求 | 倍率 |
| --- | --- | --- | --- |
| `WindowInterp-1.6.3-lsfg.zip` | LSFG | macOS 15+ | 2×–12×、CAS 锐化、性能模式 |
| `WindowInterp-1.6.3-apple.zip` | 苹果 VideoToolbox | macOS 26+，且运行时处理器支持 | 2× / 4× |

两个包功能相同，只是默认插帧内核不同。首次打开按系统提示授予「屏幕录制」权限。

## 这一版的重点

- **1.6.3 自动倍率**：按「内容帧率 × 倍率 ≤ 屏幕刷新率」自动挑倍率（30fps@100Hz→3×、24fps@100Hz→4×、60fps@120Hz→2×……）。不用再自己算，也不会再因为配错倍率每秒丢帧。
- **1.6.2 修掉「窗口尺寸决定清晰度」**：以前采集尺寸会被向下取偶，奇数宽高的窗口整幅发软；现在任意尺寸都 1:1。

## 使用提示

- 两个包使用同一个应用标识，不要同时运行。
- 声音由原应用播放，插帧会带来一点音画延迟；不支持 DRM 画面，输出 SDR / 8-bit。
- 按「现状」提供，只对你有权观看的内容使用插帧。
